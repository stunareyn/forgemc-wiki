# 💡 Concept du serveur

## 🎯 En une phrase

Un serveur de minage public où **des centaines de joueurs creusent les mêmes biomes vanilla**, font évoluer **une pioche unique**, traversent **quatre dimensions** de Prestige en Prestige, puis **renaissent** pour recommencer plus fort.

## ⛏️ Le minage est le cœur

Tout ce qui existe sur le serveur répond à une question : **est-ce que cela rend le minage plus rentable, plus rapide ou plus gratifiant ?**

| Système | Ce qu'il apporte au minage |
| --- | --- |
| Pioche | Vitesse, déblocages, plafonds d'enchantement |
| Enchantements | Vitesse, quantité, valeur, zone, Trouvailles |
| Minerais | Revenu, matériaux, collection |
| Prestige | Multiplicateur, accès aux dimensions, rythme de progression |
| Renaissance | Multiplicateur permanent, objectifs de très long terme |
| Pets et traits | Bonus permanents de rendement |
| Armures | Bonus permanents, matériaux tirés des minerais |
| Race | Spécialisation permanente |
| Boss | Minage collectif : chaque bloc cassé frappe le boss |
| Événements | Temps forts : réaction, vote, concours, heure dorée |
| Collections | Objectifs de long terme, petits bonus permanents |
| Guilde | Minage collectif, bonus d'Argent partagé |
| Skins et sons | Personnalisation, aucune puissance |

Les systèmes de support, grades, caisses, Shop rotatif, `/pv`, statistiques, menus et PNJ, servent ces systèmes et n'ont pas de progression propre.

## 🔁 Les trois boucles

```
Cycle (heures)        Miner → vendre → enchanter → forger → biome suivant → porte de Prestige
Prestige (jours)      Prestige → multiplicateur → cycle plus rapide → dimension suivante
Renaissance (semaines) Prestige X → Renaissance → multiplicateur permanent → nouvelle grande boucle
```

## 🏛️ Piliers

**Un monde partagé.** Pas de mine personnelle, pas d'instance individuelle. Les biomes sont publics et pensés pour 250 joueurs.

**Vanilla d'abord.** Biomes vanilla, minerais vanilla dans l'Overworld, premières pioches et premières armures vanilla. Le joueur reconnaît Minecraft avant de découvrir STRATA.

**Une pioche, une identité.** Le joueur ne collectionne pas des pioches : il fait évoluer la sienne.

**Temporaire contre permanent.** Tout ce qui se gagne vite se perd au Prestige. Tout ce qui se garde se gagne lentement.

**Long, mais jamais vide.** La première Renaissance demande plusieurs semaines aux plus actifs. Chaque Prestige ouvre du contenu nouveau, un boss passe toutes les deux heures, un événement toutes les vingt minutes.

**Pas de raccourci payant.** Les achats accélèrent, ils ne débloquent jamais une puissance inaccessible gratuitement. Le minerai requis par chaque nouvelle pioche ne s'achète pas.

## 🔒 Temporaire et permanent

| Remis à zéro au Prestige | En plus, remis à zéro à la Renaissance | Jamais remis à zéro |
| --- | --- | --- |
| Argent, Éclats | Rang de Prestige et son multiplicateur | Cristaux, pets, traits, armures, race |
| Pioche, niveau, enchantements | Mémoire de forge | Skins, sons, collections, titres |
| Biomes débloqués | | Clés, Œufs, guilde, grade, statistiques |
| Minerais, inventaire et `/pv` compris | | Emplacements de pet |
| Sceaux de dimension | | Multiplicateur de Renaissance |

## 🚫 Systèmes supprimés

{% hint style="danger" %}
* **Sac, bag, bundle** : supprimés. Le stockage passe par `/pv`.
* **Dynamite** : supprimée.
* **Dimensions supplémentaires** : aucune. Il existe exactement quatre dimensions.
{% endhint %}
