# 💡 Concept du serveur

## 🎯 En une phrase

Un serveur de minage public où **des centaines de joueurs creusent les mêmes biomes**, améliorent **une pioche unique**, traversent **quatre dimensions**, puis **renaissent** pour recommencer plus fort.

## ⛏️ Le minage est le cœur

Tout ce qui existe sur le serveur répond à une seule question : **est-ce que cela rend le minage plus rentable, plus rapide ou plus gratifiant ?**

| Système | Ce qu'il apporte au minage |
| --- | --- |
| Pioche | Vitesse, déblocages, plafonds d'enchantement |
| Enchantements | Vitesse, quantité, valeur, zone, Trouvailles |
| Minerais | Revenu, matériaux, collection |
| Pets et traits | Bonus permanents de rendement |
| Armures | Bonus permanents, matériaux tirés des minerais |
| Race | Spécialisation permanente du rendement |
| Rebirth | Multiplicateur permanent, recommencer plus vite |
| Collections | Objectifs de long terme, petits bonus permanents |
| Skins et sons | Personnalisation, aucune puissance |
| Compagnie | Minage collectif, petit bonus d'Argent |

Les systèmes de support, grades, caisses, Shop rotatif, `/pv`, statistiques et PNJ, servent ces systèmes et n'ont pas de progression propre. Aucun autre système n'existe sur le serveur.

## 🔁 Boucle principale

```
Miner
  → Gagner de l'Argent, des Éclats, de l'XP, des Trouvailles
  → Améliorer la pioche : enchantements (Éclats) et tier (Argent + minerai + niveau)
  → Débloquer un biome ou une dimension plus rentable
  → Obtenir pets, armures, traits
  → Optimiser son rendement
  → Atteindre la Pioche d'Éther et le niveau 100
  → Rebirth
  → Recommencer avec un multiplicateur permanent
  → Endgame : Rebirth 25, collections, pets Mythiques, traits Mythiques
```

## 🏛️ Piliers

**Un monde partagé.** Pas de mine personnelle, pas d'instance individuelle. Les biomes sont publics et pensés pour 250 joueurs simultanés.

**Une pioche, une identité.** Le joueur ne collectionne pas des pioches : il fait évoluer la sienne.

**Temporaire contre permanent.** Tout ce qui se gagne vite se perd au Rebirth. Tout ce qui se garde se gagne lentement.

**Pas de raccourci payant.** Les achats accélèrent, ils ne débloquent jamais une puissance inaccessible gratuitement. Le niveau de pioche, qui ne s'achète pas, borne la vitesse de progression.

## 🔒 Temporaire et permanent

| Réinitialisé au Rebirth | Conservé au Rebirth |
| --- | --- |
| Argent | Cristaux |
| Éclats | Pets, niveaux, étoiles |
| Tier de pioche | Traits |
| Niveau et XP de pioche | Armures |
| Enchantements | Race |
| Biomes et dimensions débloqués | Skins et thèmes |
| Minerais et blocs compressés, inventaire et /pv compris | Collections |
| Sceaux de dimension | Sons de minage, titres |
| Boosters actifs | Clés de caisse, Œufs |
| | Statistiques de vie, Compagnie, grade |

## 🚫 Systèmes supprimés

{% hint style="danger" %}
* **Sac, bag, bundle** : supprimés définitivement. Le stockage passe par `/pv`.
* **Dynamite** : supprimée définitivement.
* **Dimensions supplémentaires** : aucune. Il existe exactement quatre dimensions.
{% endhint %}
