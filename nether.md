# 🔥 Minerais : Nether

Bloc principal : **Netherrack**. Il ne tombe pas en objet : chaque bloc cassé crédite directement 5 $ et 1 XP de base, multipliée par le multiplicateur du biome.

| Minerai | Rareté | Valeur |

## Bitume

* Texture : `oil`
* Dimension : Nether
* Rareté : Commun
* Taux dans les biomes 1 à 4 de la dimension : 7 % / 3 % / 1,5 % / 0,5 %

* XP de base : 2, multipliée par le multiplicateur du biome
* Niveau minimum : 22
* Utilité : Revenu de base
