## 👤 Le profil et les réglages

| `/profil` montre                              | `/parametres` permet de régler    |
| --------------------------------------------- | --------------------------------- |
| Pseudo, grade, compagnie                      | Effets visuels des autres joueurs |
| Pioche, niveau, monde atteint                 | Messages privés                   |
| Prestige, renaissance                         | Notifications                     |
| Blocs minés, temps de jeu                     | Vente automatique                 |
| Pourcentages de collection, titres, La Course | Affichage des pets                |

`/trash` refuse les objets liés.
