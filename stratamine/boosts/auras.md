# Auras

## 🎯 Objectif

Les auras sont le **principal signe de réussite visible** en jeu. Dans un biome de 250 joueurs, une aura Mythique doit se reconnaître de loin et donner envie aux autres. Elles apportent aussi des bonus.

## ⚙️ Fonctionnement

* **Une seule aura active** à la fois.
* Visuel : surbrillance joueur et particules quand il casse un minerai.
* Types de bonus : argent, XP, Éclats, chance de bloc chanceux.

### Bonus selon la rareté

| Rareté      | Bonus                                 |
| ----------- | ------------------------------------- |
| Commune     | 1 bonus                               |
| Peu commune | 1 bonus                               |
| Rare        | 1 bonus                               |
| Épique      | 2 bonus                               |
| Légendaire  | 3 bonus                               |
| Mythique    | 3 bonus et un **effet visuel unique** |

### Obtention

| Source            | Détail                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------- |
| 🔨 Forge          | Menu des auras : Éclats, fragments d'aura et minerais indiqués par la recette de chaque aura |
| 🍀 Blocs chanceux | Fragments d'aura, auras                                                                      |

## 🔒 Règles importantes

{% hint style="warning" %}
* Une seule aura active à la fois.
{% endhint %}
