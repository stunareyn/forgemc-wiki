# Pets

## 🎯 Objectif

Les pets sont la partie **« collection vivante »** du serveur. Ils donnent des bonus, progressent avec le joueur et ne sont jamais perdus. Avec les bonus de prestige, ce sont eux qui rendent chaque cycle **plus rapide que le précédent**.

## 🥚 Les œufs

### Éclosion

{% stepper %}
{% step %}
## Monde et rareté

Chaque œuf a un **monde** et une **rareté**.
{% endstep %}

{% step %}
## Miner avec l'œuf

Le joueur garde l'œuf dans son inventaire et mine.
{% endstep %}

{% step %}
## Gagner des points

**Un coup de pioche = un point**, même si Excavation casse plusieurs blocs. Une explosion de dynamite = un point.
{% endstep %}

{% step %}
## Suivre la progression

La nombre de coup de pioche requis est affiché dans le lore de l'œuf et montre la progression.
{% endstep %}

{% step %}
## Faire éclore le pet

À l'éclosion, un pet du monde et de la rareté de l'œuf est tiré. Il va directement dans le menu des pets.
{% endstep %}
{% endstepper %}

### Quel œuf progresse ?

**Un seul œuf progresse à la fois** : celui du plus petit emplacement. Pour changer de priorité, il suffit de déplacer un œuf. Les autres gardent leur progression.

<details>

<summary>Pourquoi un coup de pioche vaut un seul point ?</summary>

Un joueur avec Excavation casse jusqu'à 25 blocs par coup. Si chaque bloc comptait, ses œufs écloraient 25 fois plus vite, et les œufs perdraient toute valeur.

</details>

## 🐾 Les pets

| Aspect          | Fonctionnement                                                                       |
| --------------- | ------------------------------------------------------------------------------------ |
| 🎁 Bonus        | Un bonus fixe par pet : argent, XP de pioche, Éclats ou chance de bloc chanceux      |
| 📈 Niveau       | Les pets équipés gagnent de l'XP en minant, leur bonus augmente avec le niveau       |
| ⭐ Fusion        | 3 exemplaires identiques donnent une étoile, jusqu'à 3 étoiles                       |
| 🔓 Emplacements | Débloqués par le premier Prestige I, le premier Prestige V et l'arbre de renaissance |

{% hint style="success" %}
**Conservation :** pets, niveaux, étoiles et emplacements débloqués ne sont **jamais perdus**. Aucun emplacement n'est vendu.
{% endhint %}

## 🔒 Règles importantes

{% hint style="danger" %}
* Un coup de pioche = un point, quel que soit le nombre de blocs cassés.
{% endhint %}
