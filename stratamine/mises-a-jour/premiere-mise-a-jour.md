# Premiere mise à jour

## 🎯 Objectif de la mise à jour

Une mise à jour rapide **prouve aux joueurs que le serveur est suivi**. Elle relance l'intérêt au moment où les premiers joueurs ont fait le tour des nouveautés, et permet d'ouvrir plus tôt sans attendre des systèmes non indispensables.

{% hint style="info" %}
Rien de ce contenu n'est nécessaire au lancement.
{% endhint %}

| Contenu                                 | Pour qui                                                   |
| --------------------------------------- | ---------------------------------------------------------- |
| 🗿 Boss                                 | Tous les joueurs d'un monde, ensemble                      |
| 🥇 Événements solo                      | Chaque joueur, avec des objectifs adaptés à sa progression |
| 🏢 Défi de Compagnie                    | Les Compagnies                                             |
| 🌙 Nuit dorée et objectif communautaire | Tout le serveur                                            |

## 🗿 Boss

### Pourquoi des boss qu'on mine

Un boss classique à combattre transformerait STRATA en MMORPG. Ici, le boss est **fait de blocs** et **se mine**. Il réunit les joueurs d'un biome autour d'un objectif commun, sans changer le cœur du jeu.

### Fonctionnement

{% stepper %}
{% step %}
## Le boss apparaît tout les X temps

Une **annonce** est faite, puis le boss apparaît dans le **dernier biome** du monde indiqué.
{% endstep %}

{% step %}
## Les joueurs présents minent dans le biome

Miner dans ce biome fait descendre la barre de vie du boss.
{% endstep %}

{% step %}
## Le boss doit être vaincu à temps

Un boss non vaincu avant la fin de sa durée limitée disparaît.
{% endstep %}
{% endstepper %}

### Récompenses

* **Garanties** au-delà d'un seuil de participation : Éclats, minerais du monde, clé de caisse.
* **Chance de récompense rare** selon la contribution : œuf, aura du boss, apparence.
* Récompense complète une fois par période.

## 🥇 Événements solo

Événements courts, plusieurs fois par jour :

| Événement       | Ce qui compte                        |
| --------------- | ------------------------------------ |
| Ruée            | Blocs minés                          |
| Main chanceuse  | Blocs chanceux                       |
| Minerai désigné | Un minerai tiré au sort, et lui seul |
| Collectionneur  | Minerais différents                  |

* Chaque participant obtient une **médaille** de bronze, d'argent ou d'or selon des objectifs **adaptés à sa progression** : un joueur de Lythos peut avoir l'or.
* Classement hebdomadaire des médailles : récompense pour les **3 premiers**.
* Seul le **meilleur résultat par type d'événement** compte dans la semaine.

## 🏢 Défi de Compagnie

* Un défi par semaine, par exemple miner ensemble une quantité de minerais d'une rareté donnée.
* Classement des Compagnies sur le défi, avec **trophée pour les 3 premières**, visible dans le menu de la Compagnie.

## 🌙 Autres contenus

* **Nuit dorée** : chance de bloc chanceux augmentée sur tout le serveur pendant quelques heures.
* **Objectif communautaire hebdomadaire** : un total de blocs à miner par tout le serveur.
