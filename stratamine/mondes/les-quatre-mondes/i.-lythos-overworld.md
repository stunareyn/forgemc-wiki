# LYTHOS (Overworld)

## 🎯 Rôle dans le jeu

Lythos est le monde d'**apprentissage**. Les noms des minerais sont familiers (charbon, fer, or, diamant) pour que le nouveau joueur comprenne tout de suite. C'est ici que Bram lui apprend le sac, la vente, la forge et le grappin.

Le prestige ramène régulièrement les joueurs avancés dans Lythos : le premier monde n'est jamais désert.
