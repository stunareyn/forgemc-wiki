# Liste des commandes

> Toutes les commandes utiles sur ForgeMC.

## Commandes générales

| Commande | Description |
| --- | --- |
| `/spawn` | [Retour au spawn] |
| `/menu` | [Ouvre le menu principal] |
| `/rtp` | [Téléportation aléatoire] |

## Économie

| Commande | Description |
| --- | --- |
| `/money` | [Affiche ton solde] |
| `/pay <joueur> <montant>` | [Envoyer de l'argent] |
| `/baltop` | [Classement des fortunes] |

## Métiers

| Commande | Description |
| --- | --- |
| `/jobs browse` | [Liste des métiers] |
| `/jobs join <métier>` | [Rejoindre un métier] |
| `/jobs info <métier>` | [Infos et revenus d'un métier] |
| `/jobs stats` | [Ta progression] |
