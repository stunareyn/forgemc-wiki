# 🎁 Caisses

## ⚙️ Règles communes

* Les caisses sont physiques au spawn. Les clés sont virtuelles, visibles et utilisables dans `/caisses`.
* Clés conservées au Prestige et à la Renaissance, non échangeables.
* Probabilités affichées en jeu, au survol de la caisse et dans l'aperçu du menu.
* Un doublon n'est jamais perdu : il est converti selon la règle de la caisse.
* Dans `/caisses` : clic gauche ouvre avec animation, clic droit affiche l'aperçu, Maj + clic ouvre par 10 sans animation, à partir de 10 clés. Un clic pendant l'animation la saute. Voir [Menus · Shop et caisses](../menus/shop-et-caisses.md).

## 🔑 Trouvailles de clés

En minant, chaque bloc cassé peut donner une clé :

| Clé | Chance par bloc |
| --- | --- |
| Clé Pets F2W | 1 sur 300 000, multipliée par le bonus de Chance |
| Clé Armure Themes | 1 sur 300 000, multipliée par le bonus de Chance |

Les deux tirages sont indépendants. Les blocs cassés par l'Excavation comptent.

## 🗳️ Caisse Vote

**Obtention** :

* 1 clé par vote, sur 3 sites, 1 vote par site toutes les 24 h, soit 3 clés par jour au maximum
* 1 clé à chaque Vote Party, pour tous les joueurs connectés. Voir [Vote Party](../evenements/vote-party.md)

| Récompense | Probabilité |
| --- | --- |
| 3 Cristaux | 40 % |
| 5 Cristaux | 20 % |
| Booster Éclats +25 %, 20 min | 15 % |
| Booster XP +25 %, 20 min | 10 % |
| Œuf de la dimension la plus avancée débloquée | 8 % |
| Clé Armure Themes | 5 % |
| Clé Pets F2W | 1,8 % |
| Son de minage Pièces | 0,2 % |
| **Total** | **100 %** |

**Doublon** : le son Pièces déjà possédé est converti en 10 Cristaux.

Valeur moyenne d'une clé : 0,40 x 3 + 0,20 x 5 = 2,2 Cristaux, plus les objets. Un joueur qui vote chaque jour sur les 3 sites gagne environ 6,6 Cristaux, 0,24 Œuf, 0,15 clé Armure Themes et 0,054 clé Pets F2W par jour, sans compter les Vote Party.

## 🐾 Caisse Pets F2W

**Obtention** :

* Trouvaille en minant : 1 chance sur 300 000 par bloc, multipliée par la Chance
* Caisse Vote : 1,8 %
* Prestiges pairs : 1 clé aux rangs II, IV, VI, VIII et X
* Chaque Renaissance : 2 clés
* Shop rotatif : 60 Cristaux
* Classement hebdomadaire des guildes

| Récompense | Rareté | Probabilité |
| --- | --- | --- |
| Loup de Givre | Peu commun | 40 % |
| Œuf de la dimension la plus avancée débloquée | Selon l'Œuf | 30 % |
| Essence Rare | Rare | 15 % |
| Essence Épique | Épique | 10 % |
| Essence Légendaire | Légendaire | 4,5 % |
| Essence Mythique | Mythique | 0,5 % |
| **Total** | | **100 %** |

**Doublon** : un Loup de Givre déjà possédé est livré normalement. Le joueur le garde pour un Éveil ou le recycle en Essence Peu commune.

Le Loup de Givre est le seul pet exclusif de cette caisse. Les Essences servent à l'Éveil de tous les pets, voir [Pets](../pets/pets.md).

| Récompense | Rareté | Type | Probabilité |

| Ninja au Saï | Épique | XP | 33 % |
| Samouraï | Légendaire | Fortune | 18 % |
| Dragon du Vent | Mythique | Argent | 4 % |
| **Total** | | | **100 %** |

Aucun pet Premium ne dépasse le meilleur pet gratuit de son type. Le Dragon du Vent est égal au Dragon d'Éther, qui s'obtient dans l'Œuf de l'Aether. Voir [Pets](../pets/pets.md).

## 🛡️ Caisse Armure Themes

**Obtention** :

* Trouvaille en minant : 1 chance sur 300 000 par bloc, multipliée par la Chance
* Caisse Vote : 5 %
* Prestiges impairs : 1 clé aux rangs I, III, V, VII et IX
* Chaque Renaissance : 2 clés
* Shop rotatif : 40 Cristaux

| Rareté du thème | Thèmes | Probabilité |
| --- | --- | --- |
| Commun | Nature, Neige | 35 % |
| Peu commun | Steampunk, Volcanic | 27 % |
| Rare | Elf Noir, Thunder | 20 % |
| Épique | Vulkaron, Drakorite | 11 % |
| Légendaire | Mythralune, Celestial | 5,5 % |
| Mythique | Dragon | 1,5 % |
| **Total** | | **100 %** |

À rareté égale, le thème est tiré au hasard, puis la pièce parmi les 4.

**Doublon** : converti en Cristaux. Commun 1, Peu commun 2, Rare 3, Épique 5, Légendaire 8, Mythique 15.

## 🌈 Caisse Armure Themes Chroma

**Obtention** : boutique uniquement. 3,49 € la clé, 5 clés pour 14,99 €, 12 clés pour 32,99 €.

**Contenu** : mêmes probabilités que la caisse Armure Themes, en version Chroma.

**Doublon** : converti en Poussière Chroma. Commun 1, Peu commun 2, Rare 3, Épique 5, Légendaire 8, Mythique 12. 30 Poussières donnent une pièce Chroma au choix, 60 pour le thème Dragon.

{% hint style="info" %}
Les doublons Chroma ne donnent **jamais** de Cristaux. Une dépense en boutique ne se convertit pas en monnaie de progression.
{% endhint %}
