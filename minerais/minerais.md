# 💎 Minerais

36 minerais, neuf par dimension. Chaque minerai correspond à une texture existante.

## 🧮 Échelle de valeur

La valeur de vente d'un minerai = unité de base de sa dimension x multiplicateur de sa place.

| Place | Multiplicateur |
| --- | --- |
| Commun, biome 1 | x1 |
| Peu commun, biome 1 | x2 |
| Commun, biome 2 | x1,8 |
| Peu commun, biome 2 | x3,2 |
| Commun, biome 3 | x3,6 |
| Rare, partagé | x12 |
| Épique, partagé | x45 |
| Légendaire, partagé | x200 |
| Mythique, partagé | x1 000 |

| Dimension | Unité de base |
| --- | --- |
| Overworld | 30 $ |
| Nether | 150 $ |
| End | 750 $ |
| Aether | 3 750 $ |

Exemple : Aurore, Légendaire de l'Aether = 3 750 x 200 = **750 000 $**.

## ⚖️ Pourquoi ces valeurs

* Un Rare vaut 3,3 fois le meilleur Commun de sa dimension. Un Mythique en vaut 278 fois.
* Dans le premier biome d'une dimension, les minerais Rares et plus font environ 45 % du revenu. Dans le troisième, environ 40 %. Les minerais rares ne sont jamais anecdotiques.
* Le Commun du biome 3 vaut plus que le Peu commun du biome 2 : changer de biome est toujours rentable.
* Aucun Commun ne vaut plus qu'un Rare de la même dimension.

## ✨ XP des minerais

| Contenu | XP de base |
| --- | --- |
| Bloc principal | 1 |
| Commun | 2 |
| Peu commun | 3 |
| Rare | 6 |
| Épique | 15 |
| Légendaire | 40 |
| Mythique | 120 |

XP gagnée = XP de base x multiplicateur d'XP du biome x (1 + bonus d'XP) x multiplicateur de Rebirth. L'XP d'un minerai n'est pas multipliée par la Fortune.

## 📦 Blocs compressés

* Avec Autocraft, 9 minerais identiques deviennent 1 bloc compressé du même minerai.
* Valeur : 9 x valeur du minerai x (1 + 3 % par niveau d'Autocraft).
* Un bloc compressé compte pour 9 unités dans toutes les recettes.
* Aucun bloc compressé n'est décompressible.

## 🔒 Règles

{% hint style="danger" %}
* Les minerais sont **liés au joueur** : impossibles à jeter, échanger ou déposer ailleurs que dans son inventaire et ses `/pv`.
* Au Rebirth, tous les minerais et blocs compressés sont détruits, inventaire et `/pv` compris. Le menu de Rebirth affiche la quantité perdue avant confirmation.
* Les noms en jeu diffèrent parfois des noms de texture. Le champ Texture fait foi pour le graphiste.
{% endhint %}
