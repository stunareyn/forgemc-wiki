# 🎁 Caisses

## ⚙️ Règles communes

* Les caisses sont physiques au spawn. Les clés sont virtuelles, visibles dans `/caisses`.
* Clés conservées au Rebirth, non échangeables.
* Probabilités affichées en jeu, au survol de la caisse.
* Un doublon n'est jamais perdu : il est converti selon la règle de la caisse.

## 🗳️ Caisse Vote

**Obtention** : 1 clé par vote, sur 3 sites, 1 vote par site toutes les 24 h. Maximum 3 clés par jour.

| Récompense | Probabilité |
| --- | --- |
| 3 Cristaux | 40 % |
| 5 Cristaux | 20 % |
| Booster Éclats +25 %, 20 min | 15 % |
| Booster XP +25 %, 20 min | 10 % |
| Œuf de la dimension la plus avancée débloquée | 8 % |
| Clé Armure Themes | 5 % |
| Clé Pets F2W | 1,8 % |
| Son de minage Pièces | 0,2 % |
| **Total** | **100 %** |

**Doublon** : le son Pièces déjà possédé est converti en 10 Cristaux.

Valeur moyenne d'une clé : 2,2 Cristaux, plus les objets. Un joueur qui vote tous les jours gagne environ 6,6 Cristaux, 0,24 Œuf et 0,15 clé Armure Themes par jour.

**Objectif de votes** : quand le serveur totalise 500 votes dans la journée, un booster global +10 % Argent d'une heure est lancé pour tous les joueurs connectés.

## 🐾 Caisse Pets F2W

**Obtention** :
* Trouvaille en minant : 1 chance sur 100 000 par bloc, multipliée par la Chance
* Caisse Vote : 1,8 %
* Chaque Rebirth : 1 clé
* Shop rotatif : 60 Cristaux
* Classement hebdomadaire des Compagnies

| Récompense | Rareté | Probabilité |
| --- | --- | --- |
| Loup de Givre | Peu commun | 46 % |
| Dragon de la Nature | Rare | 30 % |
| Dragon Mort-Vivant | Épique | 16,5 % |
| Dragon de Glace | Légendaire | 7 % |
| Essence Mythique | Mythique | 0,5 % |
| **Total** | | **100 %** |

**Doublon** : un pet déjà possédé est livré normalement ; le joueur le recycle en Essence s'il le souhaite.

Un joueur moyen ouvre environ 11 clés Pets F2W par run, soit environ 0,8 Dragon de Glace par run.

## 💠 Caisse Pets Premium

**Obtention** : boutique uniquement. 2,99 € la clé, 5 clés pour 12,99 €, 12 clés pour 27,99 €. Une clé offerte avec le grade Monarque.

| Récompense | Rareté | Probabilité |
| --- | --- | --- |
| Ninja au Shuriken | Rare | 45 % |
| Ninja au Saï | Épique | 33 % |
| Samouraï | Légendaire | 18 % |
| Dragon de Foudre | Mythique | 4 % |
| **Total** | | **100 %** |

**Doublon** : livré normalement, recyclable en Essence.

{% hint style="success" %}
Aucun pet Premium ne dépasse le meilleur pet gratuit de son type. Voir [Pets](../pets/pets.md#equite-f2w-et-premium).
{% endhint %}

## 🛡️ Caisse Armure Themes

**Obtention** :
* Trouvaille en minant : 1 chance sur 100 000 par bloc, multipliée par la Chance
* Caisse Vote : 5 %
* Chaque Rebirth : 1 clé
* Shop rotatif : 40 Cristaux

| Rareté du thème | Thèmes | Probabilité |
| --- | --- | --- |
| Commun | Nature, Neige | 35 % |
| Peu commun | Steampunk, Volcanic | 27 % |
| Rare | Elf Noir, Thunder | 20 % |
| Épique | Vulkaron, Drakorite | 11 % |
| Légendaire | Mythralune, Celestial | 5,5 % |
| Mythique | Dragon | 1,5 % |
| **Total** | | **100 %** |

À rareté égale, le thème est tiré au hasard, puis la pièce parmi les 4.

**Doublon** : converti en Cristaux. Commun 1, Peu commun 2, Rare 3, Épique 5, Légendaire 8, Mythique 15.

## 🌈 Caisse Armure Themes Chroma

**Obtention** : boutique uniquement. 3,49 € la clé, 5 clés pour 14,99 €, 12 clés pour 32,99 €.

**Contenu** : mêmes probabilités que la caisse Armure Themes, en version Chroma.

**Doublon** : converti en Poussière Chroma. Commun 1, Peu commun 2, Rare 3, Épique 5, Légendaire 8, Mythique 12. 30 Poussières donnent une pièce Chroma au choix, 60 pour le thème Dragon.

{% hint style="info" %}
Les doublons Chroma ne donnent **jamais** de Cristaux. Une dépense en boutique ne se convertit pas en monnaie de progression.
{% endhint %}

## ⚖️ Poids économique des caisses

| Caisse | Ce qu'elle peut accélérer | Ce qu'elle ne peut pas faire |
| --- | --- | --- |
| Vote | Quelques Cristaux, Œufs, boosters courts | Rien de décisif |
| Pets F2W | Un pet Légendaire Éclats | Dépasser le meilleur pet gratuit de chaque type |
| Pets Premium | Obtenir plus tôt des pets équivalents aux gratuits | Dépasser un plafond gratuit |
| Armure Themes | Skins, quelques Cristaux | Donner une statistique |
| Chroma | Skins animés | Donner une statistique ou des Cristaux |
